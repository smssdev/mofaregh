# apps/web - Vue 3 + TypeScript + Vite + Pinia + Tailwind (RTL)

واجهة عربية بالكامل (`dir="rtl"`، خط IBM Plex Sans Arabic، خصائص منطقية `start/end`). تُبنى إلى `apps/api/public/spa` ويخدمها Laravel على النطاق نفسه، فتعمل جلسة Sanctum بلا CORS.

## الشاشات (السبرنت 1)

- **الدخول**، و**حسابي** (تغيير كلمة المرور).
- **المشاريع**: كل دور يرى مشاريعه فقط؛ المدير ومدير المشروع ينشئان مشاريع.
- **المشروع**: رفع ملفات بالسحب والإفلات مع شريط تقدم وإيقاف/استئناف، حالة التطبيع، مشغل للملفات الجاهزة، وإدارة فريق المشروع.
- **المستخدمون** (مدير النظام): إنشاء وتعديل الدور والتعطيل.

## الرفع القابل للاستئناف

`src/lib/uploader.ts`: أجزاء 8 م.ب، والخادم مصدر الإزاحة. عند انقطاع الشبكة يعيد المحاولة بفواصل متزايدة (1، 2، 4… حتى 30 ث) ويستأنف تلقائيًا عند عودة الاتصال. معرّف الرفع محفوظ لكل ملف (الاسم + الحجم + تاريخ التعديل)، فاختيار الملف نفسه بعد إغلاق الصفحة يكمل من حيث توقف.
الاختبارات: `src/lib/__tests__/uploader.spec.ts`.

## الأوامر

```bash
npm install
npm run dev        # http://localhost:5173 (يمرّر /api و/sanctum إلى 127.0.0.1:8000)
npm run test
npm run build      # فحص الأنواع ثم البناء إلى apps/api/public/spa
```

> `.npmrc` يضبط `legacy-peer-deps=true` لتجاوز خلل في npm 10 مع الاعتماديات النظيرة الاختيارية لـ vitest.
