# apps/api - Laravel 11 REST API

**الحالة:** لم يُنشأ المشروع بعد (تثبيت الحزم غير متاح في بيئة الإعداد). يُنشأ في السبرنت 1 بـ `composer create-project laravel/laravel`.

## الوحدات المخطط لها

- **المصادقة والأدوار الخمسة** (Sanctum): مدير النظام، مدير المشروع، مفرِّغ، مراجع لغوي، مدقق شرعي.
- **المشاريع**: مشروع ← ملفات صوتية ← مقاطع.
- **رفع الصوت**: رفع قابل للاستئناف (resumable) إلى التخزين الكائني، ثم تطبيع بـ ffmpeg (قناة أحادية، 16kHz، WAV/Opus) عبر طوابير Redis.
- **المقاطع (segments)**: أزمنة بداية/نهاية، نص، حالة، إصدارات.
- **التكليفات (assignments)**: توزيع المقاطع/الملفات على المفرِّغين والمراجعين.
- **حالات سير المراجعة**: مسودة ← قيد المراجعة اللغوية ← قيد التدقيق الشرعي ← معتمد (مع إرجاع بسبب).
- **التصدير**: استدعاء `services/text-engine` لتوليد Word/PDF/SRT/TXT.

العقد المشترك للمستند: `shared/schemas/document.schema.json`.
